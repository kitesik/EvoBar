EvoBar 기능 비교

기준일 2026-09-06. EvoBar 열은 로컬 빌드, 65개 테스트 통과, README와 매니페스트를 직접 확인한 값. 나머지 열은 공개 저장소와 공식 페이지 기준.

읽는 법. EvoBar의 SPEC은 PokeTokenBar의 기능 집합과 거의 1:1로 대응한다 (프로바이더 12종 목록 동일, 알에서 부화 후 진화와 졸업, 희귀도와 성격과 샤이니, Rare Candy와 Mint와 Shiny Charm과 알, 48에서 192px 데스크톱 펫, 6개 언어). 차이는 세 가지다. (1) 포켓몬 대신 오리지널 동물 IP, (2) 무료 MIT 대신 유료 라인 판매, (3) 셀프사인 DMG 대신 Developer ID 서명과 공증. 반대로 PokeTokenBar는 이미 출시되어 v2.5.3, 스타 386, 프로바이더 12종이 실제로 붙어 있다.
비워 둔 칸 (확인 후 채울 것)
  • RunCat 알림 기능, 지원 언어 수
  • Mac Pet 지원 언어 수
  • PokeTokenBar 다운로드 수 (GitHub Releases 자산 다운로드 카운트는 미조회)

PokeTokenBar 대비 EvoBar가 실제로 앞서는 것과 뒤지는 것

앞서는 것
  • 상업화 가능한 오리지널 IP (PokeTokenBar는 비상업 한정)
  • 주, 월 시간 창과 출처 링크된 단가표, 커버리지 표시
  • 스프라이트 내장, 아웃바운드 최소화, 파일 권한 0600
  • Developer ID 서명과 공증 파이프라인 (Gatekeeper 우회 불필요)
  • 졸업 개체가 이름과 사용량 이력을 그대로 보존
뒤지는 것
  • 프로바이더 2종 대 12종
  • 공식 쿼터가 릴리스에서 비활성 (PokeTokenBar는 동작)
  • 캐릭터 풀 10 대 329 (아트 완성은 4)
  • 출시 0회 대 3개월간 배포 지속, 커뮤니티 지표 있음
  • 진화 분기 없음 (고정 5단계)
