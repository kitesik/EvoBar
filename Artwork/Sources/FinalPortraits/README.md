# Final-stage portrait originals

Fourteen transparent, square-pixel portraits for the seven retained lines (normal and Shiny). These are original EvoBar designs, generated with the built-in image tool on 2026-09-24. The approved normal tiger portrait set the visual direction; each line's existing final-stage side sprite provided its anatomy and palette, and each Shiny side sprite provided its alternate palette. Rejected bear-like capybara drafts were not retained.

Prompt set: **normal** — mature, upbeat, confident 3/4-front final form; chunky hard-edged pixel grid, navy outline and restrained cyan/gold glints; preserve the line's recognisable real-animal anatomy and one subtle B-grade quirk; transparent background, no text, scene or third-party character. **Shiny** — recolor the accepted normal portrait to the existing Shiny sprite's palette while retaining its pose, silhouette, anatomy and pixel scale. Species-specific constraints: capybara's long rectangular muzzle/low barrel body; raptor's feathered biped/tail/sickle claw; mammoth's trunk between two tusks; pterosaur's wing membranes attached to forelimbs.

The 1254px originals here are not locomotion frames. Runtime copies belong in `Sources/EvoBarApp/Resources/FinalPortraits`; the existing walking/menu-bar sprites stay unchanged. Do not replace those sprites with these static portraits.
