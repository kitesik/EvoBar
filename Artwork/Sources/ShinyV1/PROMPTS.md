# Starter Shiny artwork provenance

This record describes the Cat and Dog Shiny atlas delivered on 2026-09-11: 14 forms and 56 transparent state poses. Normal Atlas V2 images are unchanged. Related: [artwork provenance](../../../ARTWORK.md).

Mode: built-in image generation, fresh generation. No third-party reference image was supplied. These are dedicated alternate illustrations with the same stage identities and style, not pixel-identical hue rotations of the normal poses. The silver/ivory Cat and champagne/ivory Dog palettes remain consistent through idle, working, evolutionReady and sleeping.

Two initial Cat edit attempts retained an opaque checkerboard and were rejected, never wired into the app. A new transparent generation passed alpha and silhouette-count validation. No CLI/API fallback was used. Adjacent JSON files record source SHA-256, crop bounds, variant and exact alpha conservation. Regenerate from the repository root using `swift Scripts/prepare-art-atlas.swift --export --shiny Artwork/Sources/ShinyV1/*.png`; review with `swift Scripts/review-artwork.swift --shiny`.
